# Task 05 — Weather App

A responsive weather application built with HTML, CSS and JavaScript.

## Task requirements covered
- Fetches live weather data from a weather API
- Supports user-entered city/location
- Supports browser geolocation
- Displays current weather conditions
- Displays temperature and feels-like temperature
- Displays humidity, wind speed, pressure and cloud cover
- Displays a 5-day forecast
- Responsive design for desktop, tablet and mobile
- Loading and error states

## API
This project uses Open-Meteo:
- Geocoding API for city search
- Forecast API for weather data
- No API key is required

## How to run
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Internet access is required because weather data is fetched from the API.
4. Search for a city such as New Delhi, Mumbai, London or Tokyo.
5. Use the location button to request the browser's current location.

## Important
If browser geolocation does not work when opening the HTML file directly, run the project through a local server such as VS Code Live Server.
